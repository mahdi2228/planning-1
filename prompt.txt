# 11. COLONNES EXCEL MÉTIER

L'ordre actuel des colonnes doit être conservé.

Dans le planning manuel historique :

* AB = `Stock brut`
* AC = `moyenne vente`
* AD = `% laqué`

Une colonne supplémentaire existe :

**AE = `Écart stock laqué vs 30 %`**

Elle doit apparaître après AD.

Formule métier :

`AE = AB × (30 % - AD)`

Formule Excel :

`=+AB2*(30%-AD2)`

puis :

`=+AB3*(30%-AD3)`

`=+AB4*(30%-AD4)`

etc.

Le numéro de ligne doit être dynamique.

`% laqué` doit être interprété selon son format réel existant.

Si AD contient par exemple :

`0.20`

cela représente :

`20 %`

et la formule correcte reste :

`AB × (0.30 - AD)`.

Ne transforme jamais automatiquement `0.20` en `20` si le code existant utilise la représentation Excel standard.
